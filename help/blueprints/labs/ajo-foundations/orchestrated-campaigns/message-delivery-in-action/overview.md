# 訊息傳遞正在執行中

## 先決條件

>[!WARNING]
>
>必須先完成下列實驗，才能開始這個實驗

- **資料存放區 — 動作中的關聯存放區** **—>** [設定檔目標Dimension](../../data-stores/relational-store-in-action/profile-target-dimension.md)
- **資料存放區 — >** [設定電子郵件通道](../../data-stores/configure-email-channels/overview.md) *（此設定步驟需要3小時內完成）*

如果您尚未完成這些Labs，請立即完成後再繼續。

>[!CAUTION]
>
>本實驗需要在沙箱中委派給Adobe的子網域。 如果您是自學型且還沒有設定，請參閱[設定](../../setup.md)。

## Lab概述

在這段影片中，您會瞭解如何為本實驗建立協調的行銷活動，包括建立和建立基本計畫成員對象，以及比較設定檔與關聯式電子郵件通道之間的傳遞結果。

>[!VIDEO](https://video.tv.adobe.com/v/3486541/)

## 學習目標

- 使用數個工作流程活動來建立協調的行銷活動
- 使用「建立對象」活動來建構對象
- 取用對象以建立兩個分支，並使用在上一個實驗室建立的電子郵件通道來傳送訊息
- 測試行銷活動，並瞭解電子郵件頻道之間的行為差異

若要鎖定「基本」計畫成員，您可以在本實驗室建立行銷活動，並探索不同的協調行銷活動設定如何影響電子郵件通道設定。
