# 設定電子郵件通道

## Lab概述

在本影片中，您將瞭解如何建立本實驗中使用的兩個電子郵件通道設定 — 一個使用AEP設定檔屬性，另一個使用關聯式結構描述屬性作為執行位址。

>[!VIDEO](https://video.tv.adobe.com/v/3486540/)

## 學習目標

- 使用協調行銷活動的AEP設定檔屬性設定電子郵件頻道
- 使用關聯式結構描述屬性來設定電子郵件頻道，以用於協調的行銷活動

電子郵件通道將用於下一個實驗，協助瞭解使用一種組態與使用另一種組態的細微差別。
