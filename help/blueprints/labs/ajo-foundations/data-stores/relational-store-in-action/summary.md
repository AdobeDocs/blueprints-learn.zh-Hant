# 摘要

您透過本實驗進行了下列活動：

- 已瀏覽的結構描述和已檢視的結構描述之間的關係
- 設定設定檔目標Dimension
- 使用各種工作流程活動建立協調的行銷活動
- 使用「讀取對象」活動建構對象，並將其與關聯式結構描述屬性一起使用
- 在行銷活動中使用測試模式，並瞭解搭配使用AEP對象與關聯式結構描述時的行為
