# 關聯式存放區執行中

## Lab概述

在本影片中，您將瞭解關聯式存放區如何與即時客戶設定檔整合，以及您將在本實驗室中執行的操作，以瀏覽關聯式結構描述、設定設定檔目標Dimension，以及建置和測試協調的行銷活動。

>[!VIDEO](https://video.tv.adobe.com/v/3486539/)

## 學習目標

- 瀏覽結構並檢視關係
- 設定設定檔目標Dimension
- 使用各種工作流程活動建立協調的行銷活動
- 使用「讀取對象」活動建構對象，並使用關聯式結構描述中的屬性
- 測試行銷活動，並瞭解搭配使用AEP對象與關聯式結構描述時的行為
