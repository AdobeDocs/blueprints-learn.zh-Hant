# 摘要

在本實驗中，您已設定資料串流，並使用Postman將模擬的Web事件傳送至Edge Network，以觀察資料如何流經Adobe Experience Platform。

您透過確認設定檔已建立且符合即時設定檔中區段的資格，來驗證事件已由多個平台服務處理。 您也要驗證設定檔是否存在於Edge，確認事件儲存在資料湖中，並觀察到，由於其已排程的批次更新程式，設定檔尚未出現在設定檔快照資料集中。

透過這些步驟，您示範了事件如何在Adobe Experience Platform的Edge、即時設定檔和資料湖層中移動。
