# 作用中的設定檔

## 先決條件

>[!WARNING]
>
>下列Labs必須在開始本實驗前完成

- [Postman安裝](../../postman-setup/postman-installation.md)

如果您尚未完成這些Labs，請先完成，然後再繼續。

## Lab概述

在本影片中，您將瞭解本實驗如何模擬從Edge Network到Adobe Experience Platform的網頁造訪，以及如何驗證產生的設定檔、區段資格和資料湖事件。

>[!VIDEO](https://video.tv.adobe.com/v/3491061/)

## 學習目標

在本練習中，我們將模擬從Edge來源到Adobe Experience Platform的網頁造訪。 參觀這個實驗室後，您應該離開什麼？

- 在Adobe Experience Platform中建立及設定資料串流
- 使用Postman傳送測試Web事件至Edge Network
- 驗證即時設定檔中的設定檔建立和區段資格
- 確認Edge上有設定檔，但尚未在設定檔快照集內
- 驗證事件是否已儲存在資料湖中
