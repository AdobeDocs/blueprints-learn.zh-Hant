# 概觀

## 您將瞭解的內容

1. **Adobe Journey Optimizer架構與功能：**
   - 瞭解AJO如何原生建置在Adobe Experience Platform上，以及它適合個人化棧疊的位置
   - 探索可支援協調即時客戶歷程的核心功能
1. **資料存放區：**
   - 區分AJO中的即時客戶設定檔和關聯式商店
   - 實際操作設定及使用兩個資料存放區
1. **協調的行銷活動：**
   - 瞭解訊息傳送和通道設定背後的技術建置區塊
   - 建立及啟動協調的行銷活動，包括設定電子郵件通道
1. **歷程與決策：**
   - 瞭解歷程的技術建置組塊，以及其如何使用即時客戶設定檔
   - 瞭解Experience Edge和邊緣決策如何啟用即時、工作階段內的個人化
   - 探索決策原則、排名和使用AI編寫內容



## 目標對象

- 解決方案架構師
- 企業架構師
- 行銷人員和行銷活動管理員
- 開發人員
- Journey Orchestration專家



## 建議的體驗或熟悉度

- 歷程協調或行銷活動管理概念
- 對Adobe Experience Platform和即時客戶個人檔案的一般瞭解
- 使用REST API
- 電子郵件和跨頻道傳訊概念
- 接觸CDP、行銷自動化或其他市場技術平台
