# 概觀

## 您能學到的內容

1. **Adobe Journey Optimizer架構與功能：**
   - 瞭解AJO如何原生建置在Adobe Experience Platform上，以及其在個人化工具中的位置
   - 探索可支援協調即時客戶歷程的核心功能
1. **資料存放區：**
   - 區分AJO中的即時客戶設定檔和關聯式商店
   - 實際操作設定及使用兩個資料存放區
1. **協調的行銷活動：**
   - 瞭解訊息傳送和通道設定背後的技術建置區塊
   - 建立及啟動協調的行銷活動，包括設定電子郵件通道
1. **歷程與決策：**
   - 瞭解歷程的技術建置組塊，以及其如何使用即時客戶設定檔
   - 瞭解Experience Edge和邊緣決策如何啟用即時、工作階段內的個人化
   - 探索決策原則、排名和使用AI編寫內容



## 目標對象

- 解決方案架構師
- 企業架構師
- 行銷人員和行銷活動管理員
- 開發人員
- Journey Orchestration專家



## 建議的體驗或熟悉度

- 歷程協調或行銷活動管理概念
- 對Adobe Experience Platform和即時客戶個人檔案的一般瞭解
- 使用REST API
- 電子郵件和跨頻道傳訊概念
- 接觸CDP、行銷自動化或其他市場技術平台


## 先決條件

如果您正在以自己的步調進行此訓練營，請先完成[Postman設定](setup.md#postman-setup)，再開始進行Labs。 **設定電子郵件通道**&#x200B;及其相依Labs需要委派給Adobe的子網域，而&#x200B;**旗艦電話發佈**&#x200B;需要SMS認證。 如需詳細資訊，請參閱[設定](setup.md)。
