# 對應資料

## 概觀

在「對應」畫面中，AI/ML推薦引擎會自動在來源資料集的欄位和結構描述欄位之間對應數個屬性。 這些自動化對應稱為傳遞對應，但需要&#x200B;**仔細檢查**，因為經常會發生錯誤和不正確的對應。



![對應畫面顯示AI/ML架構的內容建議，以供傳遞對應使用](assets/overview-ai-ml-based-contextual-recommendations.png "AI/ML架構的內容建議")

>[!NOTE]
>
>AI/ML建議是以內容為基礎，您的熒幕看起來可能會與上述熒幕擷圖不同，或可能與您的鄰居不同

>[!NOTE]
>
>請注意，所有來源資料行一律視為字串
