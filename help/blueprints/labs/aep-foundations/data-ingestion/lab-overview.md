# Lab概述

## 目標

這些Labs的目的是協助您做好準備以應對資料擷取的實際挑戰。 有了這些瞭解，您將能夠處理、管理並指導團隊在生產環境中的資料實施。 雖然這個理論相當吸引人，但我們也會花時間在問題出現時進行偵錯，並將工具中的內容與本訓練營中教導的更廣泛概念連線起來。



## 有何期望

我需要您的焦點。 原因如下：資料將是您日後實施作業的基礎。

資料問題並不容易。 資料雜亂、不完整、零散，而且難以帶入您需要的系統。 這些實驗室的設計可讓您瞭解這些情境。

這些下一組Labs需要您專心致志的協助，因為您將需要接觸系統的內建。 您預計不會一次吸收所有概念，因此請花時間在實驗室中尋找方法。



## 簡述教學大綱

由於您有來源結構描述，而且您已在XDM中定義目標結構描述，因此您將需要透過對應來連線兩個結構描述。 由於此程式需要依欄位對應來區分欄位，因此您將需要學習一些可加速此程式的技巧，同時注意一些常見陷阱：

- 瞭解傳遞對應
- 修正AI/ML產生的傳遞對應
- 使用來源資料預覽以檢查任何資料品質問題

設定結構描述對應後，您需要將工作投入測試並偵錯錯誤和警告：

- 排程資料流執行
- 標籤設定檔的資料集
- 處理因必填欄位中缺少值導致的錯誤
- 處理因資料型別不符錯誤所導致的錯誤
- 處理資料擷取錯誤，並從此類故障中復原
- 反複使用測試資料以產生完整的對應集。
- 驗證及驗證已成功擷取的資料。

您將透過關聯式和非關聯式資料擷取案例學習上述概念。
