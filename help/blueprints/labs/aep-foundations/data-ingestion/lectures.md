# 講座

在Adobe Experience Platform中，資料擷取有兩種主要模式：批次和串流。 批次擷取涉及按排程間隔上傳大量資料，而串流擷取會在事件發生時即時匯入資料。 瞭解這些模式非常重要，因為這有助於企業選擇將資料引進平台的正確速度和方法，確保行銷體驗及時、相關並符合業務需求。



## 資料擷取架構

在這段影片中，您將瞭解批次和串流資料擷取背後的架構，包括來源聯結器如何透過資料準備將資料移動到資料湖和即時客戶個人檔案。

>[!VIDEO](https://video.tv.adobe.com/v/3459101/?quality=12&learn=on)





## 資料流框架

在本影片中，您將瞭解組成資料流的帳戶、資料流程和對應，以及用於驗證擷取的格式選擇和監控步驟。

>[!VIDEO](https://video.tv.adobe.com/v/3459103/?quality=12&learn=on)





## 使用複雜資料進行「資料準備」

在本影片中，您將瞭解如何將複雜的清單資料建模並擷取為陣列或地圖，因為「資料準備」只能一對一對應欄位，而無法自行建立清單。
