# 串流擷取

## 學習目標

在本練習中，我們將從串流來源載入客戶帳戶資料至Adobe Experience Platform資料湖和個人檔案。 參觀這個實驗室後，您應該離開什麼？

- 建立串流入口
- 從另一個資料流匯入對應集
- 從UI取得資料流ID和資料集ID
- 使用REST API來擷取事件
