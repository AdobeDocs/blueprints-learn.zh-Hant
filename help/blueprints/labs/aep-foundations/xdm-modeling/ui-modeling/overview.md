# UI模式

## 將來源對應至XDM

取得翻譯紙張內容的經驗，並瞭解如何探索及對應至XDM **標準**&#x200B;物件和欄位，而不是建立&#x200B;**自訂**&#x200B;物件和欄位。

您將離開的內容：

- Experience Data Model概念在現實生活中的外觀的UI知識
- 瞭解物件和欄位如何在&#x200B;**XDM欄位群組**&#x200B;的內容中定義
- 瞭解如何使用結構描述UI來探索XDM標準欄位群組



## 透過UI建立XDM

開始實際建置Connection 5G客戶帳戶綱要，利用您使用LID方法建立的綱要

您將離開的內容：

- 整體結構描述組合UI的基本瞭解
- 瞭解如何將XDM標準欄位群組新增到結構描述
- 瞭解如何從XDM標準欄位群組中移除不必要的欄位
- 能夠在結構描述中建立和使用自訂欄位群組
- 瞭解在結構描述開發😄期間如何經常儲存
- 瞭解列舉和建議值之間的差異



## 設定設定檔

瞭解設定要與即時客戶個人檔案一起使用的方案所需的步驟，從身分標籤到建立查詢方案的關係。

您將離開的內容：

- 能夠將欄位標示為身分或主要身分
- 建立兩個結構描述之間的關係
- 瞭解在啟用設定檔之前&#x200B;**測試**&#x200B;結構描述的原因
- 瞭解&#x200B;**聯合結構描述**，並透過視覺化方式檢視其運作情況
