# 講座

XDM (Experience Data Model)是Adobe的標準化架構，用於組織跨不同系統的客戶體驗資料。 這可確保來自各種來源（例如網站、應用程式和CRM）的資料以一致的方式建構，使其更易於即時統一、分析和啟用。 對於建立準確的客戶個人檔案、啟用個人化體驗，以及支援跨Adobe Experience Platform的AI驅動型深入分析，此一致性至關重要。
