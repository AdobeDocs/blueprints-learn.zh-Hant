# API模型化

## Lab概述

使用Experience Platform API對於瞭解如何自動化和操作平台的各種功能至關重要。 定義結構並瞭解這些結構描述資料的方式，是客戶在定義其資料架構時，將會在Adobe Experience Platform上執行的首要操作之一。

本實驗將向您介紹僅使用API的Adobe Experience Platform結構描述設計體驗。 您將瞭解如何利用現有XDM元件建立自己的結構描述、在XDM中新增您自己的自訂，以及識別並建立與即時客戶設定檔一起使用的各種身分描述項。

## 學習目標

能夠透過各種XDM基礎元件來建置僅使用Experience Platform API的結構描述，例如：

1. 類別
1. 欄位群組
1. 描述項
   1. 身分（包括主要）
   2. 關係
   3. 引用
