# 建置結構描述

## 結構描述元件

作為XDM一部分的所有結構描述都會以相同的方式撰寫。  結構描述一律只包含一個類別和一個或多個欄位群組。 此外，結構描述的類別會指示Experience Platform內其他系統將如何解譯資料（即以記錄為基礎的或時間序列）。

![圖表顯示由一個類別和一個或多個欄位群組所組成的結構描述](assets/overview-schema-assembly.jpeg "結構描述元件")
