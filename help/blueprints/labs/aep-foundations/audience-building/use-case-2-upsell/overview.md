# 使用案例#2 — 向上銷售

## 概觀

在本影片中，您將瞭解如何進行追加銷售使用案例，其目標鎖定透過付費和直接郵件頻道啟用的高資料使用量客戶。

>[!VIDEO](https://video.tv.adobe.com/v/3459487/?quality=12&learn=on)



**使用案例定義**

尋找過去6個月內計費資料使用總量超過140GB （滾動6個月平均）的所有客戶。 每月資料使用量>=20GB，且沒有最終電話方案的人。

在Facebook / Google和直接郵件頻道中啟用。

直接郵件個人化欄位：

- 用於問候語的名字→
- 郵寄地址→用於郵寄
- 計畫名稱→用於郵寄宣告（例如「Eric，立即升級至終極計畫！」）

## 方針

對於此使用案例，我們將評估兩個選項：

- 選項#1 （使用對象來彙總）
  - 這會讓對象執行彙總
    - 計費資料使用總和>140GB （過去6個月）
    - 帳單資料使用量平均>20GB （過去6個月）
    - 計費資料使用率高但無Ultimate計畫
- 選項#2 （使用預先彙總）
  - 這會利用將資料放在設定檔之前完成的彙總
    - 計費資料使用率高但無Ultimate計畫(Agg)
